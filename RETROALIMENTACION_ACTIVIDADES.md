# Textos de retroalimentación de las actividades

Recopilado de los scripts de cada página y de las traducciones del runtime.

Cada actividad muestra un mensaje de estado al responder o al presionar **Enviar**. Se incluyen los textos de éxito, error e informativos, además de las etiquetas accesibles que anuncian “Correcto” o “Incorrecto”.

> Los textos entre `{...}` son variables que el script completa en tiempo de ejecución (por ejemplo, la palabra formada, la letra de la ronda o la cantidad de aciertos).

> También se incluyen los mensajes intermedios que aparecen al seleccionar tarjetas o completar una pareja, porque la actividad los usa como retroalimentación antes de **Enviar**.

## Mensajes genéricos del runtime

| Clave | Texto |
|---|---|
| `multiple-choice-correct-answer` | ¡Buen trabajo! Tu respuesta es correcta. |
| `multiple-choice-try-again` | Inténtalo de nuevo |
| `fill-in-the-blank-correct-answer` | ¡Buen trabajo! |
| `fill-in-the-blank-try-again` | Inténtalo de nuevo |
| `correct-answer` | ¡Buen trabajo! <br>Tu respuesta es correcta. |
| `retry` | Reintentar |
| `fill-in-the-blank-correct-the-answers` | Por favor corregir tus respuestas. |
| `sorting-correct-answer` | ¡Buen trabajo! <br>Tu respuesta es correcta. |
| `matching-correct-answers` | ¡Todas las respuestas son correctas! |
| `matching-correct-answers-count` | Inténtalo de nuevo.<br>Tienes ${correctCount} respuestas correctas.  |
| `success-try-next-activity` | ¡Buen trabajo! ¡Intenta la siguiente actividad! |
| `answers-submitted` | ¡Tus respuestas han sido enviadas a tu maestro! |
| `validation-error` | Error de validación |

Si una actividad no define un mensaje propio, el runtime muestra uno de estos mensajes genéricos.
